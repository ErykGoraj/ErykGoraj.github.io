Memory in x86-64

Understanding how a Linux executable is organized in virtual memory.

Learning milestone

Understanding the basic memory layout of an ELF executable and inspecting it using readelf and GDB.

Program memory layout

When a Linux executable starts, different parts of the program are mapped into different regions of virtual memory.

.text Executable code
.data Initialized variables
.bss Reserved variables
heap Dynamic memory ↑
stack Stack memory ↓

The .data section

The .data section contains variables which already have an initial value. 


assembly


section .data
    bNum db 123
    wNum dw 12345
    qNum dq 12345

The .bss section

The .bss section reserves memory without storing all of that memory directly inside the executable. 


assembly


section .bss
    bvar resb 1
    dvar resd 1
    qvar resq 30000

Inspecting ELF

Linux provides the readelf utility for inspecting ELF executables. 


bash


readelf --file-header ./memory

readelf --symbols ./memory | grep main
